# 漢字命名所 — Kanji Name Generator

外国人向けに、自分の名前を日本の漢字フルネーム(当て字)に変換して楽しめるWebアプリ。
世界中の誰でもブラウザから使える。姫路城の近くで生まれたアイデア。

## 機能(v1)

- 英語・スペイン語・フランス語・イタリア語・アラビア語圏などの名前 → カタカナ → 漢字当て字
  - 主要な名前 約280件は辞書でカタカナ化、それ以外は簡易ルールで変換
  - カタカナは手で直せる(精度の逃げ道)
- スタイル4種:**侍 Samurai** / **雅 Elegant** / **福 Lucky** / **笑 Funny**
- 各漢字に英語の意味を表示、1文字ずつ「変 swap」で差し替え可能
- ネガティブな漢字(死・病・呪・罵 など)は候補から除外済み
- **スマホ壁紙ダウンロード**:墨・和紙・朱の3テーマ。時計に被らないレイアウト、青海波模様入り
- 縦書き「命名之証」カードのPNGダウンロード
- **名前パワー診断**:侍力・福・雅・笑の4ステータス+おみくじ(名前から決定論的に算出)
- **シェア機能**:Web Share APIで画像ごと共有(モバイル)、結果を再現できるシェアURLのコピー
- OGPタグ設定済み(SNSでリンクが綺麗に展開)

依存ライブラリゼロの `index.html` 1枚。

## 公開方法(世界中に届ける)

GitHub Pages にそのまま置ける:

1. リポジトリの Settings → Pages → Branch を選んで保存
2. `https://<user>.github.io/<repo>/` で即公開

独自ドメイン(例: `kanjiname.jp`)を当てると信頼感とシェアされやすさが上がる。

## 収益化ロードマップ(要壁打ち)

| フェーズ | 施策 | 備考 |
|---|---|---|
| 1. バイラル | シェアURL+壁紙に小さくロゴ | まず流入を作る。実装済み |
| 2. 物理グッズ | 命名書の印刷・額装、ハンコ、Tシャツ | Printful等の印刷オンデマンドAPIで在庫ゼロ運営 |
| 3. 姫路連携 | 土産物屋の店頭QR→その場でプリント販売 | 写真集が月100冊売れる立地が武器 |
| 4. プレミアム | 書道家の手書き版、本気の名付け相談 | 高単価。ページ内に「Coming Soon」枠設置済み |
| 補助 | 広告/投げ銭 | UXを壊さない範囲で |

## 議論したい論点

- 当て字の「面白さ」と「正しさ」のバランス
- 英語以外の発音変換の精度向上(発音辞書 or LLM API)
- 壁紙・命名書のフォント(Web版はデバイス依存。買い切りフォントで筆文字にすると化ける)
- 決済手段(Stripe Payment Links が最小工数)
