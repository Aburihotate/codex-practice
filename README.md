# 漢字命名所 — Kanji Name Generator

外国人向けに、自分の名前を日本の漢字フルネーム(当て字)に変換して楽しめるWebアプリ。
オンライン完結の収益化(フリーミアム+Stripe)を実装済み。姫路城の近くで生まれたアイデア。

## プロダクト構造(v2)

### 無料(バイラルを最大化する側)
- 名前→カタカナ→漢字当て字(スタイル4種:侍・雅・福・笑)
- 各漢字の英語の意味、1文字swap、名前パワー診断+おみくじ
- **名前物語**(スタイル別のショートストーリー自動生成)
- 壁紙3テーマ(墨・和紙・朱)… 小さな透かし入り
- シェアURL・Web Share・命名書PNG・桜の演出

### DELUXE $6.99 買い切り(収益の柱)
- 限定壁紙3テーマ:**桜**(花びら)/**金箔**(グラデ金文字+金箔散らし)/**藍波**(青海波)
- 透かしなし
- **高解像度命名書**(2倍解像度+飾り罫、印刷可能)
- **名前物語の絵巻PNG**(IG縦長サイズ)
- **タトゥー用透過PNG**(競合リサーチでタトゥー需要が有料転換の定番と判明)

### デザイン・実装(v3)
- 筆文字フォント **Yuji Syuku**(SIL OFL・商用可)をサブセット化(620字・413KB)して埋め込み。
  見出し・命名書・壁紙・絵巻・タトゥーすべて書道品質
- サイト全面リデザイン:墨色のダークUI+金/朱アクセント、和紙の命名書が浮かぶギャラリー構成
- 「魔」などダークサイドの漢字を追加排除(魔→真)

### 競合と価格根拠
- 額装プリント(namekanji.com): $78〜 / 手書き書道(namaeya): 高単価物販
- タトゥー用ステンシルPDF(nameinkanji.com): 有料DL
- 無料生成+グッズ誘導(my-kanji.com)
→ デジタル一式$6.99は「衝動買い圏内 × 競合物理価格の1/10」で刺しやすい。
   ¥1M/月 ≈ 手取り¥960/件 × **1,050件/月(日35件)**、CVR2%なら日1,750訪問で到達

## 決済を有効にする手順(バックエンド不要・30分)

`index.html` 冒頭の `CONFIG` を編集するだけ:

1. [Stripe Payment Links](https://dashboard.stripe.com/payment-links) で「Deluxe Pack $6.99」を作成
2. 決済完了後のリダイレクト先を `https://<サイト>/?unlock=HIMEJI-OMIYAGE` に設定
3. `CONFIG.stripeLink` にPayment LinkのURLを貼る

決済完了→サイトに戻る→自動アンロック(localStorage保存)。レシートにも
アンロックコード `HIMEJI-OMIYAGE` を記載しておけば別端末でも入力で解除できる。

> ⚠️ 現状はクライアントサイドのみの解除なので、コードを知っていれば無料で解除できる。
> 月商が立ち始めたらフェーズ2としてサーバー検証(Stripe Webhook+ライセンスキー発行)に移行する。
> テスト用コード: `HIMEJI-OMIYAGE`(公開前に必ず変更)

## ロードマップ

- **フェーズ2(オンライン強化)**: サーバー検証ライセンス、Stripe Webhook、多言語UI(西・仏・中)、LLMによる高精度音写
- **フェーズ3(グッズ)**: Printful/Gelato連携で額装命名書・Tシャツ・マグ(在庫ゼロ)。ハンコは国内業者と連携
- **フェーズ4(オフライン)**: 姫路の土産物屋に店頭QR+その場プリント。イベント出店(城前で外国人が並ぶ画はそれ自体がSNS素材)
