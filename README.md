# 漢字命名所 — Kanji Name Generator

外国人観光客向けに、自分の名前を日本の漢字フルネーム(当て字)に変換して楽しめるWebアプリ。

姫路城の近くで生まれたアイデア。外国人観光客の「日本っぽいもの」「漢字」への強い関心
(1万円の姫路城写真集が月100冊売れる!)を、ユーモアのある体験に変える。

## 今できること(プロトタイプ v0)

- 英語の名前(名+姓)→ カタカナ → 漢字当て字に変換
  - よくある英語名 約200件は辞書でカタカナ化、それ以外は簡易ルールで変換
  - カタカナは手で直せる(ここが精度の逃げ道)
- 4つのスタイル切替
  - **侍 Samurai/Cool**(鬼・龍・雷…)
  - **雅 Elegant**(美・華・麗…)
  - **福 Lucky**(福・宝・寿…)
  - **笑 Funny**(蚊・酢・丼…)
- 各漢字に英語の意味を表示(外国人が一番喜ぶポイント)
- 1文字ずつ「変 swap」で別候補に差し替え可能
- 縦書き「命名之証」風の表示 + PNG画像ダウンロード(SNSシェア・お土産の布石)

依存ライブラリゼロの `index.html` 1枚。GitHub Pages にそのまま置ける。

## 収益化の候補(要壁打ち)

1. **物理グッズ**:命名書の印刷版(額装)、ハンコ(印鑑)、Tシャツ — 印刷オンデマンド連携
2. **姫路の土産物屋との連携**:店頭QR → その場で生成 → その場で命名書プリント販売
   (写真集が月100冊売れる立地はここが最強の武器)
3. 広告 / 投げ銭
4. プレミアム:書道家の手書き版、意味を重視した「本気の名付け」版

## 議論したい論点

- 英語以外の名前(スペイン語・フランス語・中国語圏)の発音対応
